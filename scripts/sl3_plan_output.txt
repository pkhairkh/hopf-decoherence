9. SMALLER SANITY CHECKS AVAILABLE IN THIS SANDBOX
============================================================================

   Although the full sl_3 ℓ=3 bar complex is intractable, smaller checks are
   feasible and could provide partial verification of the conjecture:

   (i) Cartan subalgebra HH²:  A_cart = C[K1, K2] / (K1³ - 1, K2³ - 1),  dim 9.
       Over C,  x³ - 1 = (x-1)(x-ω)(x-ω²)  splits, so by CRT
       A_cart ≅ C × C × ... × C  (9 copies)  ≅ C⁹.
       C⁹ is semisimple commutative, so HH^n(C⁹, C) = 0 for all n ≥ 1.
       → dim HH²(Cartan) = 0   (NOT 3 = C(3,2))
       This shows that the Cartan contribution '3' in the conjecture is NOT
       simply HH² of the Cartan subalgebra; it comes from the mixed
       Cartan–root structure of the full Drinfeld double (the '3' counts
       deformations of the cross-relations K_i E_j = q^{a_{ij}} E_j K_i, etc.).

   (ii) B⁺(sl_3) ℓ=3 already verified:  HH² = 6 = 2|Φ⁺|   (✓ matches conjecture
        for the Borel:  C(n+1,2) = 0 since Borel has no negative-root part,
        so predicted = 0 + 2·3 = 6).

   (iii) sl_2 ℓ=3 already verified:  HH² = 3 = C(2,2) + 2·1 = 1 + 2  ✓.

   (iv) Attempt HH² of a 'Cartan × sl_2' subalgebra?
