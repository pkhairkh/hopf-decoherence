=== LES Consistency Analysis for sl_3 at ell = 3 ===

Conjecture (paper/main.tex eq. main):
  dim_C HH^2(u_q(sl_{n}), C) = C(n+1, 2) + 2|Phi^+|.
For sl_3 (n=2): C(3, 2) + 2*3 = 3 + 6 = 9.

Known dimensions:
  dim HH^2(B^+(u_q(sl_3)), C) = 5  (verified, paper Sec. 6.5)
  dim HH^2(B^-(u_q(sl_3)), C) = 5  (by Chevalley duality B^+ <-> B^-)
  dim HH^2(B^+) \oplus HH^2(B^-) = 10
  dim B^+ = 243  (3^5 = 3^(rank + 2|Phi^+|))

========================================================================
Q1: LES dimensional constraints (Mastnak-Witherspoon eq. mwles)
========================================================================

LES in degrees 1-2 (H_i := HH^i, Hb := H~_b):

  H_1(D) --i--> H_1(B) \oplus H_1(B*) --p--> Hb^1(B)
        --d--> H_2(D) --i--> H_2(B) \oplus H_2(B*) --p--> Hb^2(B)

where B = B^+(u_q(sl_3)), B* = (B^+)* \cong B^- by Chevalley, D(B) = u_q(sl_3).

Here i := bar-iota (restriction), p := bar-pi, d := delta (connecting homomorphism).

By exactness at H_2(D):
  dim H_2(D) = dim im(d) + dim im(i at deg 2).

Constraints on the split (x := dim im(d), y := dim im(i at deg 2)):
  (a) x + y = dim H_2(D)                         (LES exactness)
  (b) 0 <= x <= dim Hb^1(B)                      (image of d)
  (c) 0 <= y <= dim H_2(B) \oplus H_2(B*) = 10   (image of i at deg 2)
  (d) y <= dim H_2(D)                            (image is a subspace)

========================================================================
Q3: Can we pin down dim im(d) from first principles?
========================================================================

No, not from the LES alone -- see Q2: 10 consistent splits.

To pin down dim im(d), we need one of:
  (a) Compute dim Hb^1(B^+) directly (source of d).
      By LES exactness: dim im(d) = dim Hb^1(B) - dim im(p at deg 1).
      If dim H^1(B^+) = dim H^1(B^-) = 0, then p at deg 1 has zero source,
      so dim im(p at deg 1) = 0, and d is INJECTIVE.
      Then dim im(d) = dim Hb^1(B^+) and the LES becomes:
        dim H_2(D) = dim Hb^1(B^+) + dim im(i at deg 2).
  (b) Compute the restriction map i: H^2(D) -> H^2(B) \oplus H^2(B*) explicitly.
      This requires knowing H^2(D) -- INTRACTABLE per W2-1a
      (sparse d^2 needs 2.28 TB RAM, ~190 years).

Approach (a) is the tractable path. First step: verify dim H^1(B^+) = 0 (Q4).
Second step (out of scope here, future task): compute Hb^1(B^+) directly.

Q5: Simplified LES given the H^1 computation
========================================================================

  Computed: dim H^1(B^+) = 0
  By Chevalley duality: dim H^1(B^-) = dim H^1(B^+) = 0

  ==> dim H^1(B^+) = dim H^1(B^-) = 0, as expected.

  Consequences for the LES in degree 2:
    - The map bar-pi: H^1(B) \oplus H^1(B*) -> Hb^1(B) has zero source,
      hence zero image.
    - By exactness, ker(delta: Hb^1(B) -> H^2(D(B))) = im(bar-pi) = 0.
    - So delta is INJECTIVE: dim im(delta) = dim Hb^1(B^+).

  Simplified LES decomposition (under HH^1 vanishing):
    dim HH^2(D(B^+)) = dim Hb^1(B^+) + dim im(bar-iota at deg 2)

  Substituting the conjecture's structural predictions:
    - dim im(bar-iota at deg 2) = 2|Phi^+| = 6  (ell-th power classes)
    - dim im(delta) = C(3, 2) = 3  (Cartan-type / mixed)
  Yields dim Hb^1(B^+) = 3.

  CONVERSELY, the conjecture at A_2 is EQUIVALENT (under HH^1 vanishing)
  to the single prediction:
    dim Hb^1(B^+(u_q(sl_3)), C) = C(3, 2) = 3 at ell = 3.

Q6: Strongest statement about A_2
========================================================================

Given:
  (i)   dim HH^2(B^+) = dim HH^2(B^-) = 5  (verified)
  (ii)  dim HH^1(B^+) = dim HH^1(B^-) = 0  (computed in Q4)
  (iii) LES exactness at degree 2.

Constraints on dim HH^2(D(B^+)) = dim HH^2(u_q(sl_3), C):
  dim HH^2(D) = dim Hb^1(B^+) + dim im(bar-iota at deg 2)
  with delta injective (since HH^1 vanishes).
  Let k := dim Hb^1(B^+). Then dim HH^2(D) = k + dim im(bar-iota at deg 2).
  Constraints:
    0 <= k                                          (trivial)
    0 <= dim im(bar-iota at deg 2) <= 10                (target dim)
  Hence dim HH^2(D) \in [k, k + 10].

  CONJECTURE (dim HH^2(D) = 9) is consistent iff
    k_min = 0 <= dim Hb^1(B^+) <= k_max = 9.

  CONJECTURE REFUTATION CRITERION (sufficient):
    If dim Hb^1(B^+) > 9, then dim HH^2(D) > 9,
    REFUTING the conjecture at A_2.

  CONJECTURE VERIFICATION CRITERION (given the structural prediction
  dim im(bar-iota at deg 2) = 2|Phi^+| = 6):
    If dim Hb^1(B^+) = 3 = C(3, 2),
    then dim HH^2(D) = 6 + 3 = 9,
    VERIFYING the conjecture at A_2.

  STRONGEST STATEMENT (given HH^1 vanishing):
    The conjecture at A_2 is EQUIVALENT to
      dim Hb^1(B^+(u_q(sl_3)), C) = C(3, 2) = 3 at ell = 3.
    A direct computation of Hb^1(B^+) -- feasible at dim B^+ = 243 --
    would either VERIFY (if = 3) or REFUTE (if != 3)
    the conjecture at A_2.
